**Python · FastAPI · scikit-learn · React · Vite**  
→ [View repository](https://github.com/Chetan-code-lrca/NetraX)

### 🧭 Rajasthan Helper
A small terminal tool for weather, month-based festival lookup, and travel tips for supported Indian cities.

**Python · Click · Rich · Requests**  
→ [View repository](https://github.com/Chetan-code-lrca/rajasthan-helper)

### 🌱 GreenMile
Android application for recording sustainability activities and turning them into points, streaks, and leaderboard progress.

**Kotlin · Jetpack Compose · Firebase Authentication · Cloud Firestore**  
→ [View repository](https://github.com/Chetan-code-lrca/GreenMile-SPSU-2026)

### 🌌 Interactive Solar System Explorer
Interactive browser visualization with animated planetary orbits, playback controls, speed controls, and planet details.

**React · TypeScript · Vite · Tailwind CSS · Framer Motion**  
→ [View repository](https://github.com/Chetan-code-lrca/solar_exp)

### 👁️ Low-Level Image Feature Extraction
Digital Image Processing project for colour, texture, and shape extraction, followed by feature fusion into a numerical vector.

**Python · OpenCV · NumPy · Matplotlib · Pytest**  
→ [View repository](https://github.com/Chetan-code-lrca/low-level-image-feature-extraction)

### 👕 FitMatch AI
Next.js wardrobe application with image uploads, outfit scoring, Outfit of the Day, and rule-based stylist chat.

**Next.js · TypeScript · React · OpenAI**
