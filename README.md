**Python · FastAPI · scikit-learn · React · Vite**  
→ [View NetraX](https://github.com/Chetan-code-lrca/NetraX)

### 🧭 Rajasthan Helper
A Python CLI for current weather, month-based festival lookup, and travel tips for supported cities.

**Python · Click · Rich · Requests**  
→ [View Rajasthan Helper](https://github.com/Chetan-code-lrca/rajasthan-helper)

### 🌱 GreenMile
Android app for logging sustainability activities and turning them into points, streaks, and leaderboard progress.

**Kotlin · Jetpack Compose · Firebase · Firestore**  
→ [View GreenMile](https://github.com/Chetan-code-lrca/GreenMile-SPSU-2026)

### 🌌 Interactive Solar System Explorer
Interactive browser visualization with animated planetary orbits, playback controls, speed controls, and planet details.

**React · TypeScript · Vite · Tailwind CSS · Framer Motion**  
→ [View Solar System Explorer](https://github.com/Chetan-code-lrca/solar_exp)

### 👁️ Low-Level Image Feature Extraction
Digital Image Processing work that extracts colour, texture, and shape information and fuses it into a numerical feature vector.

**Python · OpenCV · NumPy · Matplotlib · Pytest**  
→ [View CV project](https://github.com/Chetan-code-lrca/low-level-image-feature-extraction)

### 👕 FitMatch AI
Next.js wardrobe application with image uploads, outfit scoring, Outfit of the Day, and a rule-based stylist chat.

**Next.js · TypeScript · React · OpenAI**
