## About

I'm a Computer Science & Engineering student focused on **applied AI/ML and software engineering**. I build and study systems across retrieval, agentic workflows, computer vision, cybersecurity, backend APIs, cloud infrastructure and developer tools.

I care about more than a working demo: I try to make projects **reproducible, testable, documented and honest about their limitations**. My repositories include prototypes, academic work and longer-running engineering projects; each project README describes its actual setup and current scope.

**GitHub achievements:** Pull Shark · Quickdraw · YOLO

## Selected Projects

These projects represent the areas I spend the most time exploring. Their maturity varies, so each repository documents what is implemented and what remains experimental.

### 🛡️ [NetraX](https://github.com/Chetan-code-lrca/NetraX)
Evidence-aware analysis of one-way network traffic. It accepts authorised PCAP/PCAPNG captures or supported flow CSV files, runs available detectors, and produces reviewable findings with evidence and limitations.

**Python · FastAPI · scikit-learn · React · Docker**

### 🗺️ [Fallback Atlas](https://github.com/Chetan-code-lrca/fallback-atlas)
A community outage-reporting PWA for mobile data, broadband and power availability. Includes an optional Azure Functions API, local/offline reporting and companion Android and Windows scanners. The live prototype clearly distinguishes demo markers from shared observations.

**React · MapLibre · Node.js · Azure Functions · Android · PowerShell**

### 📚 [AI Study Coach](https://github.com/Chetan-code-lrca/ai-study-coach-agents)
A multi-surface study application for planning, working with study material and generating quizzes. The repository contains separate browser, Anna-native and Streamlit editions; their model usage and data persistence differ, as documented in the README.

**Python · Streamlit · JavaScript · Vercel · Anna**

### 🎣 [PhishGuard AI](https://github.com/Chetan-code-lrca/PhishGuard-AI-ImagineCup2026)
A phishing-analysis project developed for Microsoft Imagine Cup 2026. The current browser demo uses local heuristics; the wider repository contains ML, NLP, API and cloud experiments at different stages of development.

**Python · JavaScript · scikit-learn · NLP · Azure**

### 🌱 [GreenMile](https://github.com/Chetan-code-lrca/GreenMile-SPSU-2026)
An Android sustainability application for recording activities and presenting progress through points, streaks and leaderboards.

**Kotlin · Jetpack Compose · Firebase**

### 👁️ [Low-Level Image Feature Extraction](https://github.com/Chetan-code-lrca/low-level-image-feature-extraction)
A digital image processing project exploring colour, texture and shape features, then combining them into numerical feature representations.

**Python · OpenCV · NumPy · Matplotlib · Pytest**
